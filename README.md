# Kit de reels de Neriva

Dibujos y scripts que usa la skill `neriva-reels`. La skill baja de acá la última versión al empezar cada reel.

- `kit/`: dibujos (assets.js, extra.js), motor y plantilla.
- `scripts/reel.js`: vista previa y render final con voz y efectos.
- `aportes/`: dibujos nuevos, uno por archivo (`X.nombre = () => '<svg>...</svg>'`). Se cargan solos en todos los reels.
